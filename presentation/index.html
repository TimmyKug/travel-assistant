Disaster Recovery 🛠️

  • GCP Health Check: Ping auf `/api/health` alle 30s.
  • Bei 3 Fails wirft die Managed Instance Group die VM weg.
  • Startup Script (Self-Healing):

            # Auszug startup-script (Metadata)
            gsutil -m cp "gs://$CONFIG_BUCKET/docker-compose.yml" "$APP_DIR/"
            gsutil -m cp "gs://$CONFIG_BUCKET/.env" "$APP_DIR/"
            docker compose pull
            docker compose up -d

Dank IaaS / Startup-Scripts bootet die App 100% autark neu.
