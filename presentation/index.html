Disaster Recovery 🛠️

  • GCP Health Check: Ping auf /api/health alle 30s.
  • Failover: Bei 3 Fails wirft die MIG die VM unwiderruflich weg.

Startup Script (Self-Healing):

startup-script.sh (Metadata) 

                # Lade Konfiguration aus geschütztem Bucket
                gsutil -m cp "gs://$CONFIG_BUCKET/docker-compose.yml" "$APP_DIR/"
                gsutil -m cp "gs://$CONFIG_BUCKET/.env" "$APP_DIR/"
                
                # Starte Stack komplett neu
                docker compose pull
                docker compose up -d

Dank IaaS / Startup-Scripts bootet die App vollkommen autark neu.
